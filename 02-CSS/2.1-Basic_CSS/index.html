5. Box model and total dimensions

Open style.css and change the width, padding, border, margin, and box-sizing values below.

Content area

Declared width: 240px. Padding and border are included in this box because it uses border-box.

.box-model-demo {
  width: 240px;
  padding: 20px;
  border: 5px solid;
  margin: 20px;
  box-sizing: border-box;
}

With border-box, the border-box width is 240px. With content-box, its width would be 240 + 40px padding + 10px border = 290px. Margins are outside both measurements.
